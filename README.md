# SpendIt — Smart Shopping Workspace

SpendIt — Flask-проект с гостевым каталогом, авторизацией, персонализацией, двумя режимами каталога, корзиной, избранным и встроенным мини-ассистентом.

## Главная идея

Сайт не требует регистрации для обычного просмотра. Гость может открывать каталог, искать товары, фильтровать их и смотреть карточки. Когда пользователь хочет добавить товар в корзину или сохранить его в избранное, SpendIt просит войти или зарегистрироваться.

После регистрации запускается короткая анкета персонализации. В ней нет вопроса о зарплате: используются только интересы, бюджет, приоритет покупок, сценарий и предпочитаемые бренды.

## Два каталога

В верхней панели есть переключатель:

- **Обычный** — отдельная база `instance/spendit_real.db` с реалистичным демонстрационным каталогом.
- **Шутка** — текущая исходная база `instance/spendit.db`; она специально сохранена как шуточный каталог.

ID товаров в обычной базе начинаются с `1001`, чтобы содержимое двух каталогов не пересекалось в корзине и избранном.

Переключение хранится в cookie `spendit_mode` и может меняться прямо во время просмотра сайта.

## Встроенный мини-ассистент

Главное AI-поле теперь работает как локальный mini-assistant без внешнего AI API:

- простые диалоговые фразы (`привет`, `что ты умеешь`, `как дела`);
- простые математические выражения;
- ссылки `http://` и `https://` с кнопкой открытия;
- запросы про погоду с переходом в поиск актуальной погоды;
- поиск товаров по словам запроса и бюджету;
- поиск предложений на Wildberries, Ozon и Яндекс Маркете с отображением источника и прямой ссылкой.

### Интеграция маркетплейсов

Внешние предложения хранятся отдельно в `instance/marketplace.db`: это не меняет базы обычного и шуточного каталогов и не затрагивает товары, добавленные через админ-панель. Поиск запускается из существующего поля SpendIt Assistant. Данные поиска кешируются на 6 часов, чтобы не запрашивать страницы маркетплейсов при каждом повторном запросе; интервал можно изменить переменной `SPENDIT_MARKETPLACE_CACHE_TTL` (секунды). Таймаут одного источника настраивается через `SPENDIT_MARKETPLACE_TIMEOUT`.

Адаптеры разбирают доступные структурированные данные публичных страниц. Маркетплейсы могут менять HTML, требовать авторизацию или ограничивать автоматические запросы, поэтому число результатов зависит от доступности и разметки конкретной страницы. При недоступности внешнего источника основной поиск Spendit продолжает работать. Для надёжного промышленного обновления следует подключить официальные API/партнёрские фиды, если они доступны для аккаунта проекта, и соблюдать условия площадок.

Это специально сделано как лёгкий демонстрационный слой. Для настоящей LLM его можно позже заменить на API-модель, не меняя интерфейс.

## Поиск и фильтры

Каталог поддерживает:

- обычный поиск;
- бюджет;
- сортировку;
- несколько категорий одновременно;
- отдельную кнопку **«Применить»** под категориями;
- быстрые пресеты бюджета;
- детальный просмотр карточки товара.

Старая секция «Витрина, которая знает ваш вкус» убрана. Персонализация влияет на рекомендации и результаты поиска, но интерфейс главной страницы остаётся обычным каталогом.

## Авторизация

Доступны:

- логин и пароль;
- Google OAuth / OpenID Connect через Authlib.

Google-вход активируется только после задания `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`.

Callback для локальной разработки:

```text
http://127.0.0.1:5000/auth/google/callback
```

## Запуск

```bash
python -m pip install -r requirements.txt
python app.py
```

Затем открыть:

```text
http://127.0.0.1:5000
```

## Google OAuth

Скопируйте `.env.example` и задайте переменные окружения:

```text
SECRET_KEY=change-me
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
```

## Администратор

В свежей базе создаётся администратор:

```text
login: admin
password: admin123
```

Перед реальным развёртыванием пароль необходимо заменить.

### Поиск маркетплейсов

Поиск Spendit объединяет локальные сохранённые предложения с параллельной проверкой Wildberries, Ozon и Яндекс Маркета. Сборщик использует доступные структурированные данные страниц, а для Wildberries предусмотрен JSON-ответ поискового сервиса. Доступность внешних данных зависит от правил площадок и ограничений запросов.

Для заполнения базы предложениями по стартовому набору из 100 поисковых категорий запустите из каталога проекта:

```bash
python marketplace_service.py --seed --limit 100
```

Команда делает запросы к внешним площадкам и сохраняет только реально полученные предложения. Первый запуск может занять продолжительное время; если площадка блокирует запросы, соответствующие результаты останутся пустыми и будут доступны ссылки на поиск в самом магазине. База маркетплейсов хранится отдельно в `instance/marketplace.db`; существующие базы каталога не изменяются.
